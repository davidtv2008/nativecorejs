# NativeCoreJS Refs (legacy note)

Prefer installing the full family via the **Extension Pack**:

- Marketplace / Open VSX: `NativeCoreJS.vscode-nativecore-pack`
- Or see [VSCODE_EXTENSIONS.md](./VSCODE_EXTENSIONS.md)

New apps scaffold `.vscode/extensions.json` recommending the pack plus a lite set (Refs, Routes, Pair, Contract, Diagnostics, Import Guard, Templates).

## Refs alone

`NativeCoreJS.vscode-nativecore-refs` — Go to Definition / References / Rename for `ref="name"` ↔ `this.name`.
