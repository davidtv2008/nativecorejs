# Chapter 16 — Wires (LEGACY)

> **LEGACY — removed from the teaching path.**
>
> The `@core-utils/wires.js` helpers (`wireContents`, `wireInputs`, `wireActions`, …)
> are demoted. Do not use them in new Deskflow work or scaffolding. Prefer
> `ref` + `this.bind` + `this.on` on `CoreController` / `CoreComponent`.
>
> This chapter is kept only as a historical pointer. For the current pattern, see
> [Chapter 03 — Controllers](./03-controllers.md).
