# NativeCoreJS Diagnostics

Lint-style warnings for NativeCore apps:

- `<style>` / `<script>` inside `src/views/**/*.html`
- Missing `data-view` on view roots (info)
- Alias / relative imports missing `.js`
- Top-level controller imports in `routes.js` / `routes.ts`

Marketplace ID: `NativeCoreJS.vscode-nativecore-diagnostics`
