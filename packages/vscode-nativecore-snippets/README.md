# NativeCoreJS Snippets

Official snippets for NativeCore apps (controllers, components, routes, views).

## Prefixes

| Prefix | Inserts |
|--------|---------|
| `ncc` | CoreController + factory |
| `ncmp` | CoreComponent + defineComponent |
| `ncr` | `r.register` + lazyController |
| `ncrg` | Route group |
| `ncmw` | createMiddleware |
| `ncar` | assertRefs |
| `ncb` | state + bind |
| `ncon` | this.on |
| `ncv` | View root (`data-view` + ref) |
| `ncref` | `ref="…"` |
