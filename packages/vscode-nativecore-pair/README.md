# NativeCoreJS Pair Jump

Jump between **view ↔ controller ↔ routes.js** for the current page.

## Commands / keys

| Action | Command | Default key |
|--------|---------|-------------|
| Open pair (view ↔ controller) | `NativeCore: Open Paired File` | `Ctrl+Alt+P` / `Cmd+Alt+P` |
| Cycle view → controller → route | `NativeCore: Cycle View / Controller / Route` | `Ctrl+Alt+Shift+P` |
| Jump to `r.register` line | `NativeCore: Open Route Registration` | — |
