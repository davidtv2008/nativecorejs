Next steps

Grow the app from the project CLI. Framework demos live on nativecorejs.com.

nativecore — ~/app

# scaffold a page (HTML + route wiring)

$ npm run make:view settings

# add a controller on its own when you need one

$ npm run make:controller settings

# generate a reusable custom element + registry entry

$ npm run make:component billing-card

# create route middleware (auth stays your model)

$ npm run make:middleware auth

# local development with HMR

$ npm run dev

# production build when you are ready to ship

$ npm run build
