# NativeCoreJS Explorer

Activity-bar **NativeCore** view listing SPA routes from `src/routes/routes.js`:

- Route path
- Middleware name(s) — click opens `src/middleware/<name>.middleware.js` (falls back to `createMiddleware('…')` in `app.js`)
- View HTML (click to open)
- Controller module (click to open)

Marketplace ID: `NativeCoreJS.vscode-nativecore-explorer`
