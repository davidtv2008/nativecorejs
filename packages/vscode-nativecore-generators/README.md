# NativeCoreJS Generators

Command Palette UI for NativeCore scaffold scripts:

- **NativeCore: Make (view / component / store / middleware…)**
- **NativeCore: Remove (view / component / store / middleware…)**

Runs `npm.cmd run make:* -- <name> --defaults` in the selected app folder (Windows-safe).

Marketplace ID: `NativeCoreJS.vscode-nativecore-generators`
