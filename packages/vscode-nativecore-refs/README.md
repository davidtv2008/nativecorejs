# NativeCoreJS Refs

Go to Definition, Find References, and **Rename Symbol** for NativeCore `ref="name"` ↔ `this.name` / `assertRefs('name')`.

## Use

- **F12** — jump between markup ref and controller/component member
- **Shift+F12** — all references
- **F2** — rename across `ref`, `this.x`, and `assertRefs` (paired files preferred)

Marketplace ID: `NativeCoreJS.vscode-nativecore-refs`
